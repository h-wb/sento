# Reviewing a release-please pull request

This pull request is generated by release-please from the squash commits on `main`.
The changes should be limited to `CHANGELOG.md`, `.release-please-manifest.json`,
version files (for example `mise.toml` tool versions) and lockfile bumps. Verify:

- Every `feat` and `fix` commit since the previous release has a changelog entry,
  and nothing appears that has not been merged to `main`.
- The version bump matches the Conventional Commits since the last release: features
  bump the minor, fixes the patch, and a breaking-change footer would bump the major.
- No source code changes are smuggled into the generated diff. Any code hunk is
  **blocking**.

There is nothing to test here; CI still has to pass on its own.
